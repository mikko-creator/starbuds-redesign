## Decisions and gaps

- Age gate: the Wix lightbox is client-side; its copy is NOT in the SSR harvest (no match for "You must be over 21" in audit/raw). site.json ageGate uses the live-render copy from the brief and says so in ageGate.source.
- h1: the live h1, else the first heading. Some live h1s are not names: home h1 is "SUMMIT DISPENSARY NOW OPEN" (a slide), store pages riverside/oxford/oxford-cbd have h1 "NOW OPEN"/"NOW OPEN!" (store.name uses the first heading naming Star Buds), /illinois has no h1 so its first heading (the Burbank card) is used.
- Store pages: store {name, address, phone, tel, hours, notes, links, image, map}; the Google Map component is empty in SSR, so map = {kind:map, src:""} (no coordinates).
- site.json states/stores: store pages (11) + store cards parsed from the state hubs (name / street / city, ST zip / phone + the VIEW HOURS & SHOP link). A hub card with the same phone as a store page is merged into the page object. Maryland: 0 stores parsed (its hub uses a different layout: "Star Buds Marijuana Dispensary Baltimore" + ORDER ONLINE, no zip line). New York: nav points to /buffalo (301 to shop.starbuds.us), 0 stores. Colorado: off-origin hub, only /south-boulder (a starbuds.us store page).
- Links: same-origin pages -> /x/; /_files/* (PDFs) stay absolute on the live origin (not harvested).
- Blog listings: posts[] from post-list-item (title, path, excerpt where shown, image matched by alt = title); date filled from the post models.
- Images: models store the ORIGINAL https://static.wixstatic.com/media/<id>; section/strip/column backgrounds -> sections[].bg.image / cols[].bg / repeater image role background.
- Weight: assets/source is 113 MB (largest: a 7 MB PNG and the 3.8 MB bud-pattern JPEG); the build makes WebP variants, but the repo carries the sources.
- Pages with no heading at all (h1 = ""; render the head title instead): /deals, /eula, /gratify-rewards-terms-conditions, /hr-tc, /locations.
- Map embeds with no src (the Wix Google Map component is empty in SSR): /deals, /illinois, /locations, /mississippi, /oklahoma, /rapid-city. One other embed: www.facebook.com on /media.
- Repeaters whose items carry no wixui-repeater__item class come out as ONE item holding every card (e.g. /illinois).
